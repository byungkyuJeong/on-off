# ON & OFF — 제2회 정병규 개인전

작품 갤러리 + 작품별 YouTube 영상 연결이 가능한 정적 전시 홈페이지입니다.

- 메인: index.html
- 작품 데이터: works.js
- 작품 이미지: assets/works/
- 작품 추가 방법: 작품추가_안내.txt


## 이번 버전 추가 기능
- 첫 화면에서 스위치를 직접 켜야 전시 홈페이지가 시작됩니다.
- 상단 메뉴에 PORTFOLIO가 추가되었습니다.
- `portfolio.html` 별도 작가 포트폴리오 페이지가 있습니다.
- 작품별 YouTube 영상 연결 기능은 그대로 유지됩니다.
