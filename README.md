## GitHub에 올리는 방법
1. ZIP 파일을 먼저 압축 해제합니다.
2. 압축 해제한 **안의 파일과 assets 폴더를 모두** GitHub 저장소의 main / root에 올립니다.
3. ZIP 파일 자체를 홈페이지 저장소에 올리는 것이 아닙니다.

모든 이미지 파일은 웹용으로 최적화되어 있습니다.
