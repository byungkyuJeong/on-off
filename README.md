# ON & OFF — 제2회 정병규 개인전

- 첫 화면 스위치 제거: 홈페이지 접속 즉시 본문 전시 페이지가 보입니다.
- WORKS: 작품 사진 클릭 → 상세 정보 → YouTube 영상
- PORTFOLIO: 별도 포트폴리오 페이지
- 작품 추가: `assets/works/`에 사진 업로드 후 `works.js`에 정보 추가
- GitHub Pages 주소는 기존과 동일합니다.


### 작품 페이지 스위치 인터랙션
작품 사진을 클릭하면 상세창에서 실제 토글 스위치처럼 보이는 ON/OFF 버튼을 누를 수 있습니다. ON 상태에서는 작품 이미지에 미세한 작동 효과와 신호 애니메이션이 표시됩니다.
